Suggested Call Flow

  • 1. Start on Home Show the hub, balance area, timer, progress meter, boost strip, and catalog.
  • 2. Simulate progress Use Add Points or Trigger Event to show live updates and the non-blocking toast.
  • 3. Open a game Click any game tile to open the COUPON word puzzle.
  • 4. Trigger cashout Show the summary, payment provider list, cashout data form, final confirmation, then return Home with the congratulations popup.

Implementation Choice

Built with the open web platform: standalone HTML, CSS, and JavaScript. That is the lowest-risk toolchain for a compliance call because it runs locally, has no package install, and avoids third-party CDN behavior during the demo.
